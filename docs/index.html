Open Agent Skill

Build Minecraft mods with an agent that reads first.

Auto-Mod-Minecraft turns natural-language mod requests into repository-consistent changes: project discovery, version-correct APIs, gameplay logic, data, resources, UI, networking, and evidence-based verification.

View on GitHub Installation guide

One workflow, the whole mod feature

The skill decides what to inspect and what to implement from the actual project. It does not assume that Forge, NeoForge, Fabric, or different Minecraft versions share APIs.

Discover the real project

Read loader metadata, Gradle configuration, wrapper, Java toolchain, entry points, registration style, client boundaries, and existing resource conventions.

Implement complete chains

Connect registration, runtime behavior, persistence or sync, menus and renderers, localization, models, textures, sounds, recipes, loot, and tags as required.

Verify with honest evidence

Choose targeted checks and builds while keeping compilation, game launch, and observed gameplay behavior clearly distinct.

Respect server authority

Keep client presentation separate from server-owned state and validate network actions before they mutate inventories, players, or the world.

Stay inside scope

Reuse existing systems, preserve uncommitted work, avoid unnecessary upgrades, and keep unrelated refactors out of the change.

Load context on demand

A compact dispatcher routes only the relevant references for discovery, gameplay, resources, UI, and verification.

Install once, use across mod projects

Install the single minecraft-mod-developer skill folder into your agent's user-level Skills directory. Codex and DeepSeek Harness commonly support ~/.agents/skills/; project-level Codex skills commonly use .agents/skills/.

面向 AI 的 Minecraft 模组开发工作流

Auto-Mod-Minecraft 是一个开放 Agent Skill。它要求智能体先识别当前 Minecraft 版本、加载器和工程习惯，再完成代码、资源、数据、界面与网络链路，并按实际执行情况说明验证结果。

适配现有工程

以项目源码和构建配置为准，不把 Forge、NeoForge 或 Fabric 的 API 混为一谈。

完整功能交付

把注册、运行逻辑、资源、本地化、交互、同步和构建检查作为一个功能处理。

节省无关上下文

主 Skill 只负责路由，按任务读取必要参考，并缓存稳定的项目事实。
